## Conventions

- **One folder per subject.** Each folder has a `README.md` that is its title page and index.
- **File names are lowercase kebab-case** (`hvac-reference.md`). Numbered prefixes (`00-`, `01-`) mean a series meant to be read in order.
- **Every note starts with `# Title` followed by a `[← Back to index](README.md)` link** to its folder's title page.
- **New notes:** drop the file in the right folder and add a row to that folder's README.
